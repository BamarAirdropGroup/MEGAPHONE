# MEGAPHONE
MEGAPHONE DAILY CHECK IN


#STEP - 1 
 - TOKEN နှစ် ခုလိုပါ မယ် ။ BROWSER > DEV OPTION ဖွင့် ပြီး ကောက် ရမှာ ပါ ။ DEV OPTION မဖွင့် ခင် LOGIN အရင် ဝင် ထားပါ ။  ပြီး မှ DEV OPTION ဖွင့် ပြီး PAGE ကို REFRESH ခေါက် ကာ NERWORK ကိုသွားပါ ။ SESSION ဆို တဲ့ ဟာ ရှာပြီး TOKEN ယူရပါ မယ် ။ ယူရမယ့်  TOKEN ကို ပုံ နဲ့ ပြပေးပါမယ်။


#STEP - 2

 -  CLONE THE REPO
   git clone https://github.com/BamarAirdropGroup/MEGAPHONE.git && cd MEGAPHONE && pip install -r requirements.txt


#STEP - 3

 - ADD PROXY (username:password@ip:port) 

   nano proxy.txt


#STEP - 4

 - ADD TOKEN ( Bearer_token:refresh_token) အဲ ပုံစံ အတိုင်း တကြောင်းစီ ထည့်ပါ ။

   nano token.txt


#STEP - 5 

 - RUNNING

     python bot.py
